# 经典 CNN 网络架构

## LeNet 与 AlexNet

LeNet 是最早的卷积网络之一，用于手写数字识别，确立了"卷积—池化—全连接"的基本范式。AlexNet 在 2012 年 ImageNet 竞赛上大幅领先，引入 ReLU、Dropout 与 GPU 训练，开启了深度学习的视觉时代。

## VGG 与 GoogLeNet

VGG 用统一的 3×3 小卷积堆叠出很深的网络，证明深度对性能的重要性。GoogLeNet 提出 Inception 模块，在同一层并行多种卷积核尺寸，提升多尺度特征提取能力，同时控制参数量。

## ResNet 与残差连接

随着网络加深，会出现训练误差不降反升的退化问题。ResNet 引入残差连接（跳跃连接），让网络学习残差映射 F(x)=H(x)−x，使梯度能直接回传，成功训练上百层的网络，是现代卷积架构的里程碑。

## 演进规律

经典网络的演进体现一条主线：更深的网络、更小的卷积核、更巧的连接方式（Inception、残差）、更强的归一化与正则。这些设计共同推动卷积网络在图像分类、检测与分割上的持续突破。
