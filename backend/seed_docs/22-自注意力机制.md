# 自注意力机制

## 注意力的直觉

自注意力让序列中每个位置都能"关注"其他所有位置，从而建模长距离依赖。处理一个词时，模型根据它与其他词的相关程度，对其他词的表示加权求和，得到融合了上下文的新表示。

## Query、Key、Value

每个输入位置被映射出三个向量：Query（查询）、Key（键）、Value（值）。用某位置的 Query 与所有位置的 Key 做点积，得到相关性分数，经过缩放与 Softmax 归一化为权重，再对所有 Value 加权求和得到该位置的输出。

## 缩放点积注意力

注意力计算可写为 softmax(Q·Kᵀ/√d)·V，其中除以 √d 是缩放，防止点积过大导致 Softmax 梯度消失。整个过程可并行地用矩阵运算高效完成，这是 Transformer 相比循环网络的重要优势。

## 自注意力的意义

自注意力不依赖序列的逐步递推，能一步建立任意两个位置间的联系，既能捕捉长距离依赖，又便于并行训练，是 Transformer 架构的基石。
