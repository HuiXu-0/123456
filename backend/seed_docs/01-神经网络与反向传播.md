# 神经网络基础与反向传播算法

本讲义介绍神经网络的基本结构、前向传播与反向传播算法，是深度学习的基石。

## 第一章 神经元与前向传播

神经元是神经网络的基本计算单元。每个神经元接收若干输入，对其加权求和并加上偏置，再经过激活函数得到输出。可以把一个神经元想象成一个小小的投票委员会：每个输入意见都有自己的权重，权重大的意见更有分量；偏置相当于委员会的固有立场；激活函数则像最终拍板的裁判，决定这个信号要不要继续往下传、传多强。

神经元的运算顺序固定为三步：先加权求和，再加上偏置，最后通过激活函数。这个顺序不能颠倒，因为激活必须作用在「加权和加偏置」的整体结果上，提前激活会破坏非线性表达能力。

前向传播指信号从输入层逐层经过隐藏层传递到输出层的过程。给定输入向量 x、权重矩阵 W 与偏置 b，单层的计算为 z = Wx + b，随后通过激活函数 a = f(z) 得到该层输出。多层网络就是把这个过程逐层串联：上一层的输出作为下一层的输入，像流水线一样层层加工，把原始输入逐步变换成更有用的表示。

常见激活函数包括 Sigmoid、Tanh 与 ReLU。Sigmoid 把任意实数压缩到 0 到 1 之间，常用于输出概率；Tanh 输出零均值，范围在 -1 到 1 之间；ReLU 即修正线性单元，定义为 max(0, x)，计算极快。ReLU 在正区间梯度恒为 1，能有效缓解深层网络的梯度消失问题，是现代网络的默认选择。如果没有激活函数，多层线性变换叠加之后仍然等价于一个线性变换，网络将无法拟合复杂的非线性关系——这正是激活函数存在的根本原因。

用代码表达单个神经元的前向计算非常简单：z = np.dot(x, w) + b，再取 np.maximum(0, z) 即得 ReLU 激活后的输出。输入与权重相乘求和，加偏置得到 z，再经激活函数得到本层输出。

## 第二章 损失函数

损失函数衡量模型预测与真实标签之间的差距，可以理解为给模型打分的「扣分规则」：预测越离谱，损失越大。回归任务常用均方误差（MSE），即预测值与真实值之差的平方的平均；分类任务常用交叉熵损失，它对「自信且错误」的预测惩罚极重。训练的目标就是通过调整参数，使损失函数在训练数据上尽可能小。

## 第三章 反向传播算法

反向传播（Backpropagation）是训练神经网络的核心算法。它的核心作用是高效地计算损失函数对网络中每一个参数的梯度。

反向传播通过链式法则，将损失对输出层的误差自顶向下逐层传播，计算损失对各层权重与偏置的偏导数。具体而言，先计算输出层的误差项，再利用链式法则把误差反向传播到前一层，每一层的梯度等于本层误差与该层输入的外积。直观地说，反向传播就是在追责：输出错了多少，按各条路径上的「责任比例」（权重）把误差分摊回每一个参数，让每个参数知道自己该朝哪个方向修正。

得到梯度之后，使用梯度下降法更新参数：W ← W − η·∂L/∂W，其中 η 为学习率。学习率控制每一步更新的幅度：太大容易在最优点附近来回震荡甚至发散，太小则收敛缓慢。网络利用梯度沿损失下降最快的方向更新权重，一轮一轮迭代，损失逐渐降低。

反向传播的关键在于复用前向传播缓存的中间结果，从而避免重复计算，使梯度计算的复杂度与前向传播同阶。计算图视角下，前向传播沿图的方向计算每个节点的值，反向传播沿相反方向应用链式法则累积梯度，这也是现代深度学习框架自动求导的实现基础。

如果没有反向传播，我们就无法在深层网络中高效地求解梯度，深度学习的大规模训练也就无从谈起。因此反向传播被视为连接网络结构与优化算法的桥梁。神经元、前向传播、激活、反向传播更新，构成了神经网络学习的完整闭环。

## 第四章 梯度问题与优化

深层网络在训练时可能出现梯度消失或梯度爆炸。梯度消失指反向传播过程中梯度逐层衰减，导致靠近输入层的参数几乎无法更新；梯度爆炸则相反，梯度逐层放大导致训练不稳定。Sigmoid 与 Tanh 在饱和区导数趋近于零，是深层网络梯度消失的常见诱因；ReLU 在正区间导数恒为 1，梯度不会被反复压缩，因此比 Sigmoid 更不易梯度消失。

批归一化（BatchNorm）通过把每层输入规范到稳定的分布来加速收敛并缓解梯度问题；残差连接为梯度提供了跨层直达通路；合适的权重初始化（如 Xavier、He 初始化）也能显著改善训练稳定性。

常见优化器包括 SGD、带动量的 SGD、RMSprop 与 Adam。SGD 沿小批量梯度方向直接更新；动量法累积历史梯度方向，像滚下山坡的球一样冲过小的沟壑；RMSprop 按梯度幅度自适应缩放各参数的学习率；Adam 同时结合了动量与自适应学习率，是工程实践中最常用的默认优化器。工程上还常配合学习率调度（如预热、余弦退火）与梯度裁剪来稳定大模型训练。

## 第五章 训练实践要点

训练一个神经网络的典型流程是：准备数据并划分训练集与验证集，前向传播计算预测与损失，反向传播计算梯度，优化器更新参数，如此循环若干轮（epoch）。为防止过拟合，可使用 Dropout 在训练时随机丢弃部分神经元、用 L2 正则惩罚过大权重、或在验证集指标不再提升时早停。批大小（batch size）影响梯度估计的方差与显存占用，需要在训练速度与稳定性之间权衡。
