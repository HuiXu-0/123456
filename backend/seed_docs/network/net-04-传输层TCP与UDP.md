# 传输层 TCP 与 UDP

## 传输层的职责

传输层在端到端的两个进程之间提供通信服务，通过端口号区分同一主机上的不同应用。它向上屏蔽底层网络的不可靠，提供面向连接或无连接的数据传输。

## TCP 可靠传输

TCP 是面向连接的可靠传输协议。通信前通过三次握手建立连接，结束时四次挥手释放连接。它用序号与确认应答保证数据按序、不丢失地到达，用超时重传处理丢包，用校验和检测错误。

## 流量控制与拥塞控制

TCP 用滑动窗口实现流量控制，让发送速率匹配接收方处理能力。拥塞控制通过慢启动、拥塞避免、快重传与快恢复，动态调整发送窗口，避免网络过载导致的丢包雪崩。

## UDP 与对比

UDP 是无连接的不可靠协议，不保证送达与顺序，但开销小、时延低，适合实时音视频、DNS 查询与游戏等场景。TCP 重可靠、UDP 重实时，是传输层两种互补的选择。
