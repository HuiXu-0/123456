## 网络层的职责

网络层负责把数据分组从源主机跨越多个网络送达目的主机，核心任务是寻址与路由。IP 协议为每台主机分配 IP 地址，并定义分组的格式与转发规则。

## IP 地址与子网

IPv4 地址为 32 位，常用点分十进制表示；IPv6 为 128 位以应对地址枯竭。子网掩码把地址划分为网络号与主机号，CIDR 用前缀长度灵活划分子网。同一子网内主机可直接通信，跨子网需经路由器转发。

## 路由与转发

路由器维护路由表，依据分组的目的 IP 选择下一跳。路由协议（如 OSPF、BGP）在网络中交换可达性信息、计算最优路径。转发是数据面逐跳传递分组的动作，路由是控制面计算路径的过程。

## 配套协议

ARP 把 IP 地址解析为 MAC 地址；ICMP 用于差错报告与网络诊断（如 ping）；NAT 在私有地址与公网地址间转换。这些协议共同支撑网络层的分组交付。
