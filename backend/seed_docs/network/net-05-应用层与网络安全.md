## HTTP 协议

HTTP 是万维网的应用层协议，采用请求-响应模型：客户端发出请求，服务器返回响应。它是无状态的，用 Cookie 与会话维持状态。HTTP 方法包括 GET、POST 等，状态码如 200、404、500 表示结果。HTTP/2 与 HTTP/3 提升了并发与传输效率。

## DNS 域名解析

DNS 把人类可读的域名解析为 IP 地址。它是分布式的层次化命名系统，从根域名服务器、顶级域到权威服务器逐级查询。本地缓存与递归解析器减少查询时延。DNS 多基于 UDP 传输，查询轻量。

## 网络安全基础

网络安全关注机密性、完整性与可用性。加密分对称加密与非对称加密：对称加密快、用于数据加密；非对称加密用公钥加密私钥解密，用于密钥交换与数字签名。TLS 在传输层之上为 HTTP 提供加密，构成 HTTPS。

## 常见威胁与防护

常见威胁包括中间人攻击、DDoS 拒绝服务、SQL 注入与跨站脚本。防护手段有防火墙、入侵检测、身份认证、访问控制与定期审计。安全是网络系统设计中不可或缺的一环。
