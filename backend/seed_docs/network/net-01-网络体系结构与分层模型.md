# 网络体系结构与分层模型

## 为什么要分层

计算机网络极其复杂，分层设计把通信任务拆分为若干层次，每层只负责一部分功能、并向上层提供服务、依赖下层的服务。分层降低了系统耦合，使各层可以独立演进与替换。

## OSI 七层模型

OSI 参考模型自下而上分为七层：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。它是理解网络功能划分的经典框架，每层有明确的职责与协议数据单元。

## TCP/IP 四层模型

实际互联网采用更精简的 TCP/IP 模型，分为网络接口层、网络层、传输层与应用层。网络层的 IP、传输层的 TCP 与 UDP、应用层的 HTTP 与 DNS 共同支撑了今天的互联网。

## 封装与解封装

数据自上而下逐层封装：每层给上层数据加上本层首部，形成本层的协议数据单元；接收方自下而上逐层解封装，剥去首部并交给上层。分层与封装是网络通信的核心思想。
