# 物理层与数据链路层

## 物理层

物理层负责在传输介质上传送原始比特流，规定电压、频率、接口形状与编码方式等机械、电气特性。它把数字比特转换为可在双绞线、光纤或无线信道上传播的信号。带宽与误码率是物理层的关键指标。

## 数据链路层

数据链路层在相邻节点间提供可靠的帧传输。它把比特流组织成帧，通过帧首部的地址实现节点寻址，并用校验（如 CRC）检测传输错误。链路层还负责流量控制与介质访问控制。

## 以太网与 MAC 地址

以太网是最广泛使用的局域网技术。每个网卡有全球唯一的 MAC 地址，以太网帧用源 MAC 与目的 MAC 标识收发方。交换机依据 MAC 地址表在局域网内转发帧。CSMA/CD 曾用于共享介质的冲突检测。

## 与上层的衔接

数据链路层向网络层提供帧传输服务，把网络层的 IP 分组封装进帧并交给物理层发送。物理层与数据链路层共同构成网络通信的底层基础。
