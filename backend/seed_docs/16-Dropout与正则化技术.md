# Dropout 与正则化技术

## Dropout 的原理

Dropout 是一种针对神经网络的正则化技术。训练时以概率 p 随机将一部分神经元的输出置零，使网络不能过度依赖某些特定神经元，从而学到更鲁棒、更冗余的特征表示。它相当于在训练中集成了大量共享权重的子网络。

## 训练与推理差异

训练阶段随机丢弃神经元；推理阶段保留全部神经元，但需按保留概率缩放激活（或在训练时做反向缩放），以保证期望输出一致。常用丢弃概率在 0.2 到 0.5 之间。

## 与其他正则手段的配合

Dropout 常与权重衰减（L2 正则）、数据增强、早停等手段配合使用。在卷积层中也有空间 Dropout 等变体。归一化层在一定程度上也带来正则效果。

## 抑制过拟合的整体策略

抑制过拟合是一个系统工程：增大数据量与多样性、降低模型复杂度、加入正则项、使用 Dropout 与早停，并通过验证集监控泛化表现，是深度学习训练的常规组合拳。
