# 机器学习基础与大模型微调

本讲义涵盖机器学习的基本范式，以及大语言模型的参数高效微调技术。

## 第一章 机器学习范式

机器学习的本质是让计算机从数据中自动学习规律，而不是依靠人工编写规则。机器学习主要分为监督学习、无监督学习与强化学习。

监督学习使用带标签的数据训练模型，就像学生做带标准答案的练习题：模型给出预测，与标准答案对照，错了就修正。典型任务包括分类与回归。分类预测离散的类别标签，例如判断一封邮件是否为垃圾邮件、识别图片中的物体类别；回归预测连续的数值，例如预测房价或气温。

无监督学习从无标签数据中发现结构，像在没有答案的情况下自己整理笔记。典型任务包括聚类与降维：聚类把相似的样本自动分组，例如把用户按行为习惯分群；降维在尽量保留信息的前提下压缩特征维度，便于可视化与后续建模。强化学习则让智能体在与环境的交互中通过奖励信号学习策略。

特征是模型观察世界的窗口。特征工程指从原始数据中构造、选择对预测有用的输入变量，特征的质量往往比模型的选择更能决定效果上限。损失函数衡量预测与真实目标的差距，是模型优化的方向盘：回归常用均方误差，分类常用交叉熵。训练过程就是不断调整参数让损失变小。

## 第二章 过拟合与正则化

过拟合指模型在训练集上表现很好，但在测试集上泛化能力差，本质是模型记住了训练数据中的噪声而不是学到了普适规律。这就像学生把习题册的答案背得滚瓜烂熟，一到新考卷就不会做。过拟合最典型的表现是训练误差持续下降而验证误差开始回升。

缓解过拟合的常用方法包括正则化（如 L1、L2）、Dropout、数据增强与早停。L2 正则化通过惩罚过大的参数来限制模型复杂度，使决策边界更平滑；L1 正则化还能让部分参数稀疏归零，起到特征选择作用。Dropout 在训练时随机丢弃一部分神经元，迫使网络不依赖任何单一通路。早停在验证集指标不再提升时终止训练。交叉验证把数据轮流划分为训练与验证子集，用来更可靠地评估泛化能力、选择超参数。从偏差-方差权衡的角度看，正则化以略微增大偏差为代价显著降低方差。

## 第三章 大模型微调技术

预训练大模型在海量语料上学习通用知识，但通用模型无法直接完美适配特定任务（如客服对话、专业领域问答），微调（Fine-tuning）就是让预训练模型适配特定下游任务的过程。可以把预训练模型看作受过通识教育的毕业生，微调则是岗前培训。

全参数微调更新模型的全部权重，理论上能最大程度适配下游任务，效果通常最好，但显存与算力开销巨大：训练时除了权重本身，还要保存梯度与优化器状态，对大模型动辄需要数百 GB 显存，且每个任务都要保存一份完整模型副本。

参数高效微调（PEFT）只更新少量参数即可达到接近全参微调的效果。LoRA（Low-Rank Adaptation，低秩适配）是其中代表：它冻结原始权重 W，用两个低秩矩阵 A 与 B 来近似参数更新的增量 ΔW = BA，秩 r 远小于原维度，从而把可训练参数量降低几个数量级，显存占用大幅下降，推理时还可把 BA 合并回原权重做到零额外延迟。其它 PEFT 方法还包括 Adapter（在层间插入小型瓶颈网络）与 Prompt Tuning（只学习软提示向量）。工程上选择全参微调还是 LoRA，取决于数据量、算力预算与任务与预训练分布的差距。

## 第四章 指令微调与对齐

指令微调（Instruction Tuning / SFT，监督微调）使用「指令-响应」格式的样本训练模型，使其更好地理解并遵循自然语言指令，从「续写文本的语言模型」转变为「听得懂要求的助手」。指令数据的多样性与质量直接决定模型的泛化表现。

在此基础上，对齐（Alignment）让模型输出符合人类偏好与价值观。基于人类反馈的强化学习（RLHF）先用人类对回答的排序训练奖励模型，再用强化学习优化生成策略；DPO（直接偏好优化）则跳过显式奖励模型，直接在偏好对上优化，流程更简单、训练更稳定。预训练、指令微调、对齐三个阶段串起来，构成了现代对话式大模型的完整训练管线。
