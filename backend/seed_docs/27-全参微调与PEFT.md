# 全参微调与参数高效微调

> 来源：Hugging Face PEFT 官方文档整理 ｜ 许可：Apache-2.0
> 说明：本文为依据上述开放许可来源整理的中文知识条目，供本项目 RAG 知识库检索接地使用。

## 全参微调

全参微调（Full Fine-tuning）在下游任务上更新预训练模型的全部参数。它效果上限高，但算力与显存开销大，每个任务都要保存一份完整的模型副本，部署成本高。

## 参数高效微调

参数高效微调（PEFT）只更新少量新增或选定的参数，冻结绝大部分原始权重，在显著降低成本的同时逼近全参微调的效果。常见方法包括 LoRA、Adapter 与 Prompt Tuning。

## 主要方法

Adapter 在每层中插入小型瓶颈模块，只训练这些模块。LoRA 用低秩矩阵表示权重增量。Prompt/Prefix Tuning 在输入端引入可学习的虚拟提示向量，只优化这些向量。它们都把可训练参数压到原模型的很小比例。

## 工程优势

PEFT 让单卡微调大模型成为可能，且不同任务只需保存各自的小增量权重，便于多任务切换与部署。它已成为大模型时代领域适配的主流路线，与全参微调形成成本-效果的不同取舍。
