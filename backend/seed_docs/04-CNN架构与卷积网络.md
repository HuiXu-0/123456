# CNN 架构与卷积神经网络

卷积神经网络（CNN）是处理图像等网格结构数据的经典深度学习架构。CNN 的核心思想是局部连接、权重共享和池化下采样，三者共同大幅减少参数量并赋予模型对平移的鲁棒性。

## 第一章 卷积层

卷积层的主要作用是提取局部空间特征。卷积核（也称滤波器）是一个小的权重矩阵，它在输入图像上按一定步长滑动，每停留一处就与覆盖区域做逐元素相乘再求和，得到输出特征图上的一个值。可以把卷积核想象成一只拿着小手电筒的眼睛：它一格一格扫过整张图片，每次只看一小块局部区域，寻找边缘、纹理、角点这类局部模式。

权重共享指同一个卷积核在图像所有位置使用同一组参数：无论猫耳朵出现在图片左上角还是右下角，都由同一个「猫耳检测器」负责识别。这与全连接层每个连接都有独立参数形成鲜明对比，使参数量从百万级骤降到几百个，也让特征检测天然具备平移等变性。

卷积的两个关键超参数是步长（stride）与填充（padding）。步长控制卷积核每次滑动的距离，步长越大输出特征图越小；填充在输入边缘补零，使边缘像素也能被充分覆盖。输出特征图的边长可由公式计算：output = (input − kernel + 2 × padding) / stride + 1。例如 32×32 的输入、5×5 的卷积核、填充 2、步长 1，输出仍为 32×32。

一个卷积层通常包含多个卷积核，每个卷积核产生一张特征图（feature map），不同特征图对应不同类型的局部特征。卷积之后一般接 ReLU 激活引入非线性。

## 第二章 池化层

池化层（Pooling）对特征图做下采样，可以降低特征图的空间尺寸，从而减少后续计算量与参数量，并增强平移不变性——目标稍微移动几个像素，池化后的输出几乎不变。

最大池化（Max Pooling）取窗口内的最大值，保留最显著的特征响应，是最常用的选择；平均池化（Average Pooling）取窗口内的平均值，保留整体强度信息。典型配置是 2×2 窗口、步长 2，使特征图边长减半。现代网络也常用步长大于 1 的卷积或全局平均池化来替代传统池化层。

## 第三章 感受野

感受野（Receptive Field）指输出特征图上一个点能「看到」的原始输入区域大小。随着卷积层与池化层的堆叠，感受野逐层扩大：浅层神经元只能看到几个像素，负责检测边缘与纹理等低级特征；深层神经元的感受野覆盖大半张图，能够组合出物体部件乃至整体语义。小卷积核多层堆叠（如两层 3×3 等效一层 5×5 的感受野）比单个大卷积核参数更少、非线性更强，这是 VGG 网络的核心设计哲学。

## 第四章 经典网络结构

一个典型的 CNN 由「卷积 → 激活 → 池化」模块反复堆叠，最后接全连接层输出分类结果。LeNet 是 CNN 的开山之作，用于手写数字识别，奠定了卷积-池化-全连接的基本范式。AlexNet 在 2012 年 ImageNet 竞赛中以巨大优势夺冠，引爆了深度学习浪潮，其贡献包括使用 ReLU 激活、Dropout 正则与 GPU 训练。VGG 用统一的 3×3 小卷积核堆出 16-19 层，结构规整、易于迁移。

ResNet（残差网络）通过残差连接（shortcut）让输入可以跨层直达输出，使梯度在反向传播时拥有恒等通路，成功训练了上百层的网络，解决了深层网络的退化问题。残差连接此后成为几乎所有深层架构（包括 Transformer）的标配组件。

## 第五章 工程实践视角

用框架实现卷积层只需一行：例如 nn.Conv2d(in_channels, out_channels, kernel_size=3, stride=1, padding=1)，后接 nn.ReLU() 与 nn.MaxPool2d(2)。工程上需要权衡的要点：卷积核数量与层深决定模型容量与显存占用；批归一化几乎是卷积层的标配，可加速收敛；数据增强（随机裁剪、翻转、颜色抖动）是图像任务对抗过拟合的第一手段；部署侧常用深度可分离卷积（MobileNet）在精度与计算量之间取得平衡。
