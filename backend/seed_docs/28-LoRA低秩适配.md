# LoRA 低秩适配

## 核心思想

LoRA（低秩适配）的核心思想是：冻结预训练模型的原始权重，用两个低秩矩阵 A 与 B 的乘积来表示权重更新增量 ΔW = B·A。微调时只训练 A、B，原权重保持不变。由于秩 r 远小于权重维度，可训练参数量大幅下降。

## 低秩假设

LoRA 基于一个观察：微调引起的权重变化往往具有较低的"内在秩"，即可以用低维结构很好地近似。因此用低秩分解就足以捕捉适配所需的变化，而无需更新整个权重矩阵。

## 推理与部署

推理时可把 B·A 合并回原权重，不引入额外延迟。不同任务训练出不同的低秩增量，部署时按需加载，单个基座模型即可服务多个任务，存储开销极小。

## 扩展

QLoRA 在 LoRA 基础上对基座模型做 4 比特量化，进一步压缩显存，使在单张消费级显卡上微调超大模型成为可能。LoRA 已成为参数高效微调中最广泛使用的方法之一。
